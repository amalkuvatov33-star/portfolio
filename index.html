Практика

Кейсы и лабораторные работы

Проект 01

Анализ событий безопасности Windows в Wazuh

Исследовал повторяющиеся алерты, связанные с Windows Event ID 4673. Проверял имя процесса, пользователя, PID, привилегию и поля аудита. Рассматривал необходимость сопоставления событий с дополнительными журналами.

Статус: первичный анализ выполнен; первопричина требует дальнейшей проверки.

Проект 02

Проверка изменений списка слушающих портов

Исследовал алерт Wazuh "Listened ports status (netstat) changed". Проверял слушающие порты, связанные процессы и состояние служб. Сопоставлял назначение обнаруженных сервисов с лабораторной конфигурацией.

Проект 03

Диагностика дискового пространства Wazuh

Проверял заполнение файловой системы и размеры журналов. Изучал расположение алертов и архивных данных. Анализировал влияние нехватки свободного места на работу SIEM.

Проект 04

Автоматизация на Python

Использовал язык программирования Python для анализа сетей, процессов и логов.

Проект 05

Использование Kali Linux для проверки процессов и сетей

Изучал сетевые инструменты и проверял работу процессов в изолированной среде.

Проект 05

Использование POWERSHELL

Узнаю команды для аналитики и расследование событий, как постоянный инструмент в использование Windows

Проект 07

Анализ и исправление конфигураций безопасности с помощью Wazuh SCA

Изучал результаты проверок безопасности и выявлял настройки со статусом Failed. Анализировал требования проверок и текущую конфигурацию системы. Определял необходимые изменения для устранения несоответствий требованиям безопасности. Проверял результаты повторных оценок, чтобы подтвердить устранение проблем.

Основная цель: улучшение конфигурации безопасности системы на основе результатов Wazuh SCA.

Подход

Как я анализирую инциденты

01

Проверяю фактические данные

Сначала оцениваю реальные события, журналы, процессы и временные метки.

02

Сопоставляю контекст

Сравниваю события по времени, пользователям, PID, портам и сетевым соединениям.

03

Отделяю факты от предположений

Не делаю выводов без достаточной проверки и подтверждения данных.

04

Проверяю соответствие требованиям

Сопоставляю конфигурации с нормативными требованиями и результатами SCA.

05

Фиксирую выводы

Записываю наблюдения, ограничения и последующие шаги для дальнейшего анализа.
